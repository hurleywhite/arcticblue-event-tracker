# ArcticBlue Event Tracker

A self-contained, static HTML page that tracks every in-person AI event ArcticBlue is considering for Q2/Q3 2026. Built from the source `.docx` tracker doc; deployable directly to Vercel.

**Live demo:** https://arcticblue-event-tracker-deploy.vercel.app/

## How to build

```bash
# 1. Re-extract verified URLs from the source doc (only if doc was updated)
python3 src/extract-urls.py

# 2. Rebuild the HTML page
python3 src/build.py

# 3. Open public/index.html in a browser to verify
open public/index.html
```

```bash
cd public
vercel deploy --prod --yes
```

## How to add a verified URL for an event

The build only links cards that have a **real, verified URL** — extracted from the source doc's hyperlinks OR added manually after someone has visited the page in a browser. **The build never invents URLs.**

To add one manually:

1. Open `data/event-urls-manual.json`
2. Add an entry like `"31": "https://www.ai-bigdataexpo.com/north-america/"` (the key is the event number from the source doc; the value is a real URL you've confirmed in a browser)
3. Re-run `python3 src/build.py`

Anything in `event-urls-manual.json` overrides the doc-extracted URL, but the build will refuse to use any URL that isn't actually in one of the two JSON files.

## Tech stack

- **Source:** Python 3.11 + `python-docx` for parsing the source .docx
- **Output:** Single static HTML file with inline CSS and JS — no framework
- **Hosting:** Vercel (static deploy from `public/`)
- **Fonts:** Hanken Grotesk + Fragment Mono from Google Fonts

No build tooling beyond Python. No npm, no React, no Next.js. The page is intentionally trivial to serve.

## What's in the page

- **Hero** with today's date, last-updated stamp, and the ArcticBlue logo
- **KPI strip** — 4 metrics (total tracked, upcoming, archived, regions)
- **Today / Up-next callout** — auto-updates based on the build date
- **Filters** — search, priority, region, type — applied client-side
- **Upcoming events grid** — each card links to a verified URL (when one exists) or is non-clickable (no hallucination)
- **Archive** — collapsed by default; events whose end-date has passed
- **Footer** — version + last-built timestamp

## Pointers for the next AI agent

Read **`AGENT-CONTEXT.md`** before changing anything. The most important rules:

1. **No invented URLs.** If you don't have a verified URL, the card stays unlinked.
2. **White-primary aesthetic.** Internal ArcticBlue tools are white background, black text, gray rules, minimal blue accent. Don't pivot to dark mode without explicit user direction.
3. **Single self-contained HTML file.** No build chains, no React, no bundlers. The page must work when opened locally with a double-click.
4. **The source `.docx` is the source of truth for events.** Don't fork the event list into JSON or YAML — re-parse the doc.

See `HANDOFF.md` for the prioritized improvement list.
